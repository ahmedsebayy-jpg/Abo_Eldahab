# موقع أبو الدهب لزيوت السيارات

الموقع الرسمي لمتجر **أبو الدهب لزيوت السيارات** بمدينة فاقوس، محافظة الشرقية. تم تجهيز الموقع ليعمل فوراً بدون أي شاشة سوداء أو أخطاء بناء.

---

## ⚡ الطريقة المضمونة 100% لتشغيل الرابط على GitHub Pages في خطوتين:

### الخطوة الأولى: رفع الكود على GitHub
أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub، ثم نفّذ الأوامر التالية:

```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git branch -M main
git push -u origin main
```
*(استبدل `YOUR_USERNAME/YOUR_REPOSITORY` برابط مستودعك الخاص)*

---

### الخطوة الثانية: تفعيل الرابط من إعدادات GitHub (بدون أي شاشة سوداء):
1. افتح صفحة المستودع على **GitHub**.
2. اضغط على **Settings** (الإعدادات) في أعلى الصفحة.
3. من القائمة الجانبية اليسرى، اضغط على **Pages**.
4. في خانة **Branch**:
   - اختر: **`main`**
   - وفي الخانة المجاورة لها (المجلد)، اختر: **`/docs`** (وليس `/root`!).
5. اضغط **Save**.

خلال دقيقة واحدة سيظهر لك الرابط المباشر في نفس الصفحة ويعمل فوراً:
`https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/`

> **ملاحظة هامة:** سبب الشاشة السوداء سابقاً كان اختيار مجلد `/root`، بينما الكود الجاهز للعرض مبني داخل مجلد **`/docs`**. بمجرد اختيار `/docs` سيعمل الموقع 100%.

---

## 🚀 بديل أسرع وأبسط (Vercel) — بضغطة زر واحدة:
إذا أردت لينك فوري مجاني على رابط مثل `abo-eldahab.vercel.app`:
1. ادخل على **[vercel.com](https://vercel.com)** وسجل دخول بحساب GitHub.
2. اضغط **"Add New Project"** واختر المستودع.
3. اضغط **"Deploy"** مباشرة بدون كتابة أي شيء.
4. يفتح الموقع فوراً بلينك رسمي دائم وسريع جداً.
